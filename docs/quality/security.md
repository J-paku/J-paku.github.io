# 公開してよいものの線引き

これは公開サイトで、認証もバックエンドもデータベースも無い。守るべきは**載せてはいけないものを載せないこと**に尽きる。

## 業務データを載せない

**実画面のキャプチャを使わない。** 業務データが写り込むため、画面はすべて自作の SVG(図解・アニメーション)で再現している。
デモ動画も実データではなくモックデータで再構成したものを撮る。
この原則を外したくなったら、その画面に固有名詞・座席・氏名・社内の識別子が1つも無いことを確かめる。

## 訪問者の情報を集めない

- 天気の取得で送るのは**固定の緯度経度だけ**。訪問者の位置情報は扱わず、応答も保存しない
- アクセス計測(GoatCounter)は Cookie を使わない。計測タグは `src/app/html-shell.tsx` が読み込む(送信を包む `src/lib/analytics.ts` は現在どこからも呼ばれていない)
- ブラウザに残すのはテーマと村の進行だけ。窓口は `src/lib/preferences.ts` → [../architecture/data-flow.md](../architecture/data-flow.md)

## リポジトリに秘密を置かない

- 静的エクスポートなので、ビルドに入る値はすべて公開されると考える。API キーを要する外部サービスを足さない
  (Open-Meteo をキー不要という理由で選んでいる → [ADR 0005](../decisions/0005-runtime-weather-fetch.md))
- `.env` は `.gitignore` 済み。`.claude/` も同様でリポジトリに入らない

## 外部への通信を足すとき

静的エクスポートの自己完結に対する例外は現在1つだけ。増やす前に次を満たすか確かめる。

1. 認証情報を要さない
2. 訪問者の情報を送らない
3. **落ちても画面が止まらない**(失敗を無害な既定値へ丸められる)

3つ目を満たせないなら、実行時ではなくビルド時に取り込む方法を先に検討する。
