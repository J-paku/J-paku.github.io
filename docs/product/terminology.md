# 用語

コード・コンテンツ・文書で同じ語を同じ意味で使う。**日本語の画面名と英語の識別子が対応している**ので、両方を挙げる。

## 画面

| 語 | 識別子 | 意味 |
|---|---|---|
| 村 | `village` / `VillagePage` | トップ(`/`・`/ko/`)。歩いて回るマップ |
| 一覧 | `list` / `Directory` | `/list/`・`/ko/list/`。経歴・作品カード・折りたたみ詳細 |
| 作品ストーリー | `story` / `Story` | `/works/<slug>/`。iPhone 枠の中で場面が切り替わるスクロールストーリー |

## 村

| 語 | 識別子 | 意味 |
|---|---|---|
| ワールド | `World` | 1枚のマップ。屋外の町(`town`)と屋内の自室(`room`)がある |
| 村全体 | `WorldSet` | ワールドの集合。`startWorldId` のワールドの `start` から始まる |
| マス | `Cell` | 整数座標。左上原点で `tiles[y][x]` |
| タイル | `Tile` | マスの地面の種類。通行可否は種類で決まる |
| 構造物 | `Structure` | 家・机・テーブル・ベッド・ロボット・ポスト・街灯・経歴碑など。占有マスは通行不可 |
| 会話地点 | `Spot` | 話しかけられる立ち位置。構造物と `structureId` で結ばれる |
| コース順 | `Spot.order` | 1始まりの通し番号。**全ワールドを通して**連番。無い地点はコース外 |
| ワープ | `Warp` | 乗るか扉にぶつかると別のワールド・マスへ移る |
| 時間帯 | `DayPhase` | `dawn` / `day` / `dusk` / `night` の4段階 |
| 経歴碑 | `monument` | 町の上寄り中央の 2×2 の石碑。在籍企業を読める。**コース外** |

## コンテンツ

| 語 | 識別子 | 意味 |
|---|---|---|
| locale | `Locale` | `'ja'` か `'ko'`。URL だけで決まる |
| 作品 | `Work` | 一覧のカード1枚。`slug` が同一性の鍵 |
| 状態 | `WorkStatus` | `'published'`(公開)か `'wip'`(制作中) |
| 折りたたみ詳細 | `Work.detail` | カード内で開く「症状 → 原因 → 解決」の節の列 |
| ストーリー | `Work.story` | 専用ページ(`/works/<slug>/`)の中身。`detail` とは別物 |
| 場面 | `WorkStoryScene` | ストーリーの1コマ。SVG 1枚 + 技術チップ |
| 経歴 | `Career` | 在籍1社分。`id` が ja/ko 共通の安定キー |
| 派遣先 | `CareerDetailAssignment` | 在籍1社の中で替わった現場1件 |

## 言い換えないもの

`glyph`(カードの装飾漢字)・`context`(どういう文脈で作ったか)・`scope`(守備範囲)は
いずれも content の項目名であり、一般語として訳さずそのまま使う。
