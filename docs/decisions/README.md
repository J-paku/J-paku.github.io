## 書くときの決まり

- **リポジトリ内に根拠があるものだけを書く。** コードやコミットから「たぶんこういう理由だろう」と想像して ADR を作らない
- 各 ADR は `Status` / `Context` / `Decision` / `Consequences` / `Alternatives Considered` を持つ
- 判断が覆ったら、元の ADR を消さずに `Status` を `Superseded by ####` に変え、新しい番号で書く
