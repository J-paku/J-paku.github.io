# 0015. 他の検査と重なるテストを消し、言語に依らない E2E は ja だけで回す

## Status

Accepted(2026-10-11、テストの大掃除の2回目)。[0011](0011-extreme-constraints.md)は「テストを消す」に新しいADRを求める。
1回目(同じ日)に消したテストと、2回目にkoの回を外したE2Eを、ここにまとめて記録する

## Context

- 0011は、テストを消すことを制約を下げる側に数え、新しいADRを求めている。1回目の削除は理由を各コミットの本文に書いたが、ADRは書いていなかった
- 2回目の前のE2Eは178件(`npx playwright test --list`)。journey・clock・day-night・fishingの4つのspecは、テストをja(`/`)とko(`/ko`)で2回ずつ登録する繰り返しで、koの回が55件あった
- 一方でflight・umbrella・idle-loop・storage-blocked・dialog-focus・story・scene-refetchと、journey・fishingの一部のテストは、「言語に依らないのでjaだけで見る」と注釈してjaだけで回している
- 型([0003](0003-content-outside-src.md))が両言語に求めるのは必須の欄だけで、koだけ欠けた必須の文言はビルドで落ちる。
  任意の欄(`StopText`の`arrive`・`talk`・`link`・`entries`)は、片方の言語にだけ書いても値が言語の間でずれても型は通る

## Decision

### 1回目に消したテスト

理由の正本は各コミットの本文。どれも、消す前に同じ振る舞いを見ている別の検査を確かめた。

| 消したもの                                                                      | 同じものを見ている検査(コミット)                                                                                                                                                               |
| ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| journey「町の自宅の扉から部屋へ戻る」(ja/koの2件)                               | umbrellaの晴れの日のテストが、自宅前で上を押すと扉を通って部屋の出口手前へ戻るのを位置まで見る。扉を押して入る経路はjourneyの「自宅の扉を click/hold/drag して入る」(`781bf7f`)                |
| journey「次へボタンで名刺工房まで自動で移り、着いたら会話が開く」(2件)          | flightが次へで名刺工房の会話窓が開いて前に立つことを、day-nightの完走がja/koで次へから名刺工房の会話窓が開くことを見る(`781bf7f`)                                                              |
| journey「8 か所すべて話すと案内が変わり一覧のボタンへ焦点が移る」(2件)          | day-night「夜で雨でも8か所のコースは最後まで通る」がja/koで同じ次へ連鎖・完走の案内・出口への焦点を見る。ここにだけあった出口の`data-bounce`の断定は、先にそちらへ移した(`bcd48b0`・`781bf7f`) |
| day-night「時計を {段階} の帯に固定すると村がその段階になる」(4段階×2言語の8件) | 同じファイルの「4段階のどれも…シートそのものが入れ替わる」が段階ごとに同じ手順で同じ`data-phase`を断定する。段階はDateだけから決まり保存を読まない(`b5d6824`)                                  |
| fishingの糸の`animation-name`をkeyframesの名前で見る断言1つ                     | 隠れて差し込まれたことは`data-observed-line=hidden`が、隠す長さは`animation-duration`が見る。名前はCSSの書き方に縛られるだけ(`b5d6824`)                                                        |
| 単体のsprites-night「焼き上がった夜のシートも昼と同じ index を同じ順序で持つ」  | `sprites.test.ts`が夜を含む4段階のindexを比べる。夜だけ鍵の並びを逆にした版でそちらが落ちるのを確かめてから消した(`0aa7128`)                                                                   |
| flightの、自宅前から地図で経歴碑へ飛ぶ同じ移動を記録し直していた6本             | 記録を1回だけ取る1本にまとめ、元の6本の題名を`test.step`の名前にして断定を移した。断定の数(expect 120個)と文言は前後で同じ(`bc09599`)                                                          |

### 2回目: 言語に依らないE2Eはjaだけで回す

テストごとに、断定しているものが言語で変わりうるかを見る。変わりうるものだけkoでも回し、ほかはjaだけにする。
物差しはjaだけで回しているspecの注釈(「飛び方は言語に依らない」「焦点の動きも吹き出しの位置も言語では変わらない」など)に合わせた。

koでも回すもの:

- **言語の接頭を保つ導線。** `/ko`のまま作品・一覧と村を行き来する(journeyの2本)
- **文言の折り返し。** jaは`PhraseText`が入れる`<wbr>`で、koは空白で折るので仕組みが違う(journeyのタッチ端末の案内)
- **テストが言語で操作を分けているもの。** fishingの3本はkoでは吹き出しのボタンで投げ、jaのZとは別の入力の経路を通る
- **koの全部の地点の文言で次へを最後までつなぐ完走**(day-nightの1本)。1回目にjourneyの完走を消した時のkoの受け皿で、koで全部の地点を通るのはこれだけ

jaだけで回すもの: 歩き・扉・地図・会話窓の焦点と本文送り・A/B・保存・テーマ・当たり判定・卓上時計の窓・段階のシート・灯り・天気の層。
koの文言は要素を探す名前に使うだけで、断定は言語で変わらない。jaだけのテストは、ループの中で`if (prefix !== '') continue`より下に置く(clockはkoの行を外す)

| spec      | koの回(前 → 後) | koでも回すテスト                                               |
| --------- | --------------- | -------------------------------------------------------------- |
| journey   | 34 → 3          | 名刺工房から作品と一覧へ・一覧から村へ・タッチ端末の案内       |
| clock     | 10 → 0          | なし                                                           |
| day-night | 7 → 1           | 夜で雨でも8か所のコースは最後まで通る                          |
| fishing   | 4 → 3           | 吹き出しから投げる・すべて釣り上げた後・池の中へは踏み込めない |

E2Eの全体は178件から130件になる。

## Consequences

- **koの画面を直接押さなくなる範囲。** koの村で、地図(開く・地点へ飛ぶ・凡例)・卓上時計の窓・設定メニューのテーマ・扉・会話窓の本文送りと焦点・会話窓と地図のA/B(koのA/Bを押すのは釣りのタッチ操作だけになる)・再読み込み・考え事の吹き出し・段階のシート・灯り・天気の層
  - これらに出るkoの文言(地図・時計・設定の名前、町の`hint`・`noTarget`・時計の結果の一言、経歴碑の社名)が画面に出ることは、E2Eでは見なくなる
  - koの本文が窓からあふれるかで変わる本文送りも、koでは見ない。送り方の作りは言語に依らず、jaのテストは本文があふれる寸法を作って見ている
  - 1回目にjourneyの扉のテストをja/koの受け皿にしたが、今はjaだけ。扉の位置と行き先は言語に共通の世界のデータ(`content/world.ts`)
  - journeyで8か所を晴れの日に巡るのは経歴碑のテストで、これもjaだけになる。koの完走は夜・雨のday-nightが見る
  - 北の道と経歴碑のkoの回が見ていたkoの`journey.link`(mailtoのhref)と`monument.entries`(数・ロゴ)は任意の欄で型が見ないので、
    jaのE2Eが見るjaの値と同じであることを`src/lib/content/village-text-pair.test.ts`が見る
- **防ぐ仕組み**
  - 必須の欄が両言語にそろうこと(型。0003)
  - 任意の欄の有無、言語に依らない値(リンク先・経歴のロゴ)と経歴の数がjaとkoで同じで、文言が空でないこと(単体の`src/lib/content/village-text-pair.test.ts`。型が見ない所を埋める)
  - ビルドの`scripts/verify-export.mjs`が、両言語のトップ・一覧・作品ストーリーがあることと、書き出したHTML(koを含む)が参照する静的ファイル(経歴碑のロゴなど)が`out/`にあることを見る
  - axe(`scripts/check-a11y.mjs`)・日本語改行の検査(`scripts/check-ja-linebreak.mjs`)・Lighthouse CI(`lighthouserc.json`)は、今も`/ko`の村と一覧を測る。axeは会話窓も開く
  - 残るkoのE2E: 上の表の7件と、fishingのタッチ操作(koだけ)・directory 2件・layout 1件・not-found 3件(`/ko`の404と、koの案内から村・一覧へ戻る導線)
- jaだけのテストに、文言の長さ・折り返し・言語の接頭で変わるものを断定に足すときは、koでも回す(`continue`より上へ移す)
- 所要がどれだけ縮むかは、この記録の時点では測っていない

## Alternatives Considered

- **ja/koの両方を回し続ける** — 言語で結果が変わらない回を2回走らせるだけで、断定を足さない。採らない
- **koの回を全部やめる** — 接頭を保つ導線・折り返し・koだけの入力の経路はkoでしか見えないので採らない
- ほかに比べた案の記録は無い
