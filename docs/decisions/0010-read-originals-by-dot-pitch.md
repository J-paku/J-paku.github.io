# 0010. 原画はドットの間隔を測った格子で読み、色は近い既存の文字へ写して、近似できない色だけ文字を足す

## Status

Accepted(2026-09-30、`15074c9` 「傘を差した立ち・歩きのコマを、利用者の原画シートから体ごと写したものに替える」。
写し方は`src/lib/pixel/umbrella-original.ts`と`src/lib/pixel/umbrella-original.fixture.ts`の見出し)。
[0008](0008-verbatim-pixel-art-originals.md) のうち、色の写し方と格子の扱い、読み取り時の除去・移動を置き換える

## Context

[0008](0008-verbatim-pixel-art-originals.md) は、原画を写した後は1ドットも変えないと決め、そのうえで次の2つを書いた。

- 原画の色が既存のパレットに無ければ、近い既存の文字で代用せず`src/lib/pixel/palette.ts`に文字を足す
- 原画は写す先の格子に合った寸法で用意することになり、`568c5a9`(参照画像を 16×24 格子・13.4px ピッチで採取し、胴を 20 行に詰めた)のように格子へ採り直して行を詰める写し方は取れない

2026-09-29 の`7499346`は傘のコマを描き直し、本文に「ADR 0008 は原画を 1 ドットも変えないと決めているが、この傘の描き直しは利用者の指示による」と 0008 の例外であることを書いて、主人公のシートを 32×32 の画布にした。
体は今も 16×24 で、0008 の「主人公は16×24」は体の大きさとしては合っているが、シートの1コマは体の上と左右に余白を足した 32×32 の画布である(`src/lib/pixel/actors.ts`の`PLAYER_HEIGHT`・`PLAYER_BODY_*`・`PLAYER_FRAME_*`とその見出し)。

この決定を初めて当てたのが`15074c9`である。原画は利用者から受け取った1枚のシートで、4行×8コマ・夜の色調、行は正面・背面・右向き・左向き(`src/lib/pixel/umbrella-original.ts`の見出し)。
原画の1ドットは画素1つではなく、横5.55px・縦6.0pxの升だった(`src/lib/pixel/umbrella-original.fixture.ts`の見出し)。

`15074c9`は、この原画を下の Decision の手順で読み、32×32 の画布へ置いた。本文と注釈は読んだ手順と数値を書いているが、0008 の写し方を採らなかった理由は、傘の柄の置き方を除いて書いていない。

## Decision

原画を写した後は1ドットも変えないこと、直したい所は原画を差し替えて写し直すことは 0008 のまま。
変えるのは、原画を文字マトリクスへ読む手順の次の4点。

- **格子は原画のドットの間隔を測って決める。** 原画が写す先の格子に合った寸法である必要はない。
  原画の辺の強さ(隣の画素との色差)を升の境目と升の中央で比べ、全コマで境目が最もはっきりする間隔を升の大きさにする(`15074c9`は横5.55px・縦6.0px)。
  位相はコマごとに体の部分で合わせ、升ごとに端1pxを除いた中央部の最頻色(各色16段に丸めて数える)を代表色にする。
  原画の1ドットを升1つとして読むので、`568c5a9`のように写す先の行数へ詰めることはしない
- **色は近い既存の文字へ写す。** 0008 の「近い既存の文字で代用せず文字を足す」を改める。
  原画が夜の色調で描かれているので、`src/lib/pixel/palette.ts`の各文字の夜の色(`src/lib/pixel/palette-phase.ts`の night)と比べて近い文字を選び、
  夜の混色で出せない明るい色(灯りに照らされた肌など)は昼の色と比べる。選べる文字は部分で絞る(傘の布は傘の文字と輪郭だけ、体は主人公の文字と足した文字)
- **文字を足すのは、既存の文字で近似できない色だけ。** `15074c9`が足したのは傘の中間色・柄・橙・明るい橙・照らされた髪先の5色。
  足した文字の昼の色は夜の混色からの逆算で出し、逆算できない明るい色は原画の色をそのまま昼の色にする(`src/lib/pixel/palette.ts`の注釈)
- **読み取りの段階で、原画のドットを外す・動かすことがある。** 0008 の「どのドットも位置と色を原画のまま置く」と、
  「夜のランタンの重ねと時間帯の色(`src/lib/pixel/palette-phase.ts`)は、写した絵に後から掛ける。写す段階の絵には手を入れない」から外れる。
  `15074c9`がしたのは次の3つで、どれも`src/lib/pixel/umbrella-original.ts`の見出しに写し方として書かれている。理由はその見出しに書かれたものだけを挙げる
  - 白い縁取りを透明(`'.'`)として読む(除去)。理由は書かれていない
  - 傘の柄(`|`)を、柄の中心線が通る列の升へ置く(移動)。理由は「幅2〜3pxでドットより細く、升の中央の色では升の境目に掛かると消える」
  - 原画が提げていたランタン(ガラス・枠と、体に触れていないその輪郭)を抜き(除去)、夜は`src/lib/pixel/actors.ts`が`src/lib/pixel/lantern.ts`の面を原画のランタンの位置へ重ねる。
    重ねる方は 0008 の決まりどおり写した絵に後から掛けるものだが、抜く方は写す段階の絵に手を入れている。抜いた理由は見出しにも`15074c9`の本文にも書かれていない

## Consequences

- 「1ドットも変えない」を確かめる相手は、読み取った直後の行列になった。`src/lib/pixel/umbrella-original.fixture.ts`が読み直すための条件
  (格子・位相・代表色の取り方、コマごとの原画上の位置)と行列を持ち、`src/lib/pixel/sprites-art.test.ts`が`src/lib/pixel/umbrella-original.ts`のコマと1ドットも違わないことを確かめる。
  写した後に手で直すとこれで落ちる。原画そのものは今もリポジトリに無く、読み取った行列が原画と合っているかは目で確かめるしかない
- 傘の立ち・歩きのコマでは、0008 の「どのドットも位置と色を原画のまま置く」「写す段階の絵には手を入れない」が読み取りの段階で守られていない(Decision の4点目)。
  外した・動かしたドットは読み取った直後の行列に含まれるので、上の突き合わせでは食い違いにならない
- 近い文字へ写した所は、原画の色ではなくその文字の色で描かれる。近似できるかどうかの線引きを数値で書いた記録は無い
- 原画に無いコマ(傘を取り出す・開く・畳む・しまう途中)は、`15074c9`では実装が既存の傘の形を原画の立ち姿へ載せて組み、
  実装が描いたものと注釈に書いた(`src/lib/pixel/actors.ts`)。原画に無いコマをどう扱うかは、0008 にもこの記録にも決まりが無い

## Alternatives Considered

- **0008 のとおり、原画にあって既存のパレットに無い色ごとに文字を足す** — `15074c9`は採らなかったが、比べて退けた理由の記録は無い
- **原画を写す先の格子に合った寸法で用意し直す**(0008 の Consequences が想定した形) — 比べた記録は無い
- ほかに比べた案の記録は無い
