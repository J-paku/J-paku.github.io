# 0006. 昼夜の判定を JST 固定にする

## Status

Accepted(2026-09-20、`5fcd9a1`。実装は `src/utils/day-phase.ts`)

## Context

村の空を時間帯で変えるとき、基準を**訪問者のローカル時刻**にするか**舞台の時刻**にするかを選ぶ必要があった。
村の舞台は大阪である。

## Decision

UTC から計算した **JST(UTC+9 固定)** で時間帯を決める。訪問者のタイムゾーンは見ない。
段階は `DAY_PHASES = ['dawn', 'day', 'dusk', 'night']` の4つで、**この組が唯一の正本**。

## Consequences

- どの国から見ても同じ空になり、共有されたスクリーンショットと実際の表示が食い違わない
- JST に夏時間が無いため、固定オフセットの計算で足りる(タイムゾーンのライブラリを入れない)
- 段階を足すと、シート焼き・CSS 規則・テストの網羅を手書き配列で持っている側が**型エラーで落ちる**。
  黙って未検証のまま出荷されない代わりに、段階の追加は必ず複数箇所の修正を伴う
- 訪問者の現地時刻と一致しない(夜に見ても昼の村になることがある)

## Alternatives Considered

- **訪問者のローカル時刻** — 「大阪の村」という設定と食い違い、スクリーンショットの再現もできない
- **時間帯を持たず常に昼** — 採らなかった。時刻で変わること自体がこの画面の見せ場
