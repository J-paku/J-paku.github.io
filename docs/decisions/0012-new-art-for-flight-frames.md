# 0012. 原画の無い飛ぶ姿のコマは新しく描き、原画が届いたら写して置き換える

## Status

Accepted(2026-10-10。利用者の判断として記録する。コマの定義は`src/lib/pixel/flight-art.ts`)。
[0010](0010-read-originals-by-dot-pitch.md) が決めずに残した「原画に無いコマをどう扱うか」のうち、飛ぶ姿のコマだけを決める(傘の途中のコマは決めない)

## Context

[0008](0008-verbatim-pixel-art-originals.md) と [0010](0010-read-originals-by-dot-pitch.md) は、原画がある絵をどう写すかを決めた。
0010 は Consequences に、原画に無いコマ(傘を取り出す・開く・畳む・しまう途中)は`15074c9`で実装が既存の傘の形を原画の立ち姿へ載せて組んだこと、
原画に無いコマをどう扱うかは 0008 にも 0010 にも決まりが無いことを書いた。

2026-10-10 に、村の自動の移動を、経路を歩いてたどる動きから行き先へまっすぐ飛ぶ動きに替えた。
飛ぶ間の主人公には飛ぶ姿のコマが要るが、利用者の原画に飛ぶ姿は無い。

## Decision

原画の無い飛ぶ姿のコマは、実装で新しく描く。利用者の判断による。

- 描いたのは主人公の飛ぶ姿の6コマ`player-fly-{down,up,right}-{0,1}`(下・上・右の向きごとに2コマ)。
  左向きは右向きの左右反転で出し、夜のシートにはランタンを提げた版を載せる。定義は`src/lib/pixel/flight-art.ts`
- 決めるのは飛ぶ姿のコマだけ。0010 が決めずに残した原画に無いコマのうち、傘を取り出す・開く・畳む・しまう途中のコマは、引き続き決まりが無い
- 飛ぶ姿の原画が後から届いたら、新しく描いたコマをその原画で置き換える。写した後は1ドットも変えないことは 0008、原画を読む手順は 0010 のとおり

## Consequences

- 飛ぶ姿の6コマには、0008・0010 が絵を確かめる相手にしている原画も、読み取った直後の行列も無い。絵が正しいかは目で確かめるしかない
- 原画に無いコマのうち決まりがあるのは飛ぶ姿のコマだけになった。傘の途中のコマと、これから出てくる原画に無いコマは、0010 の時点と同じく決まりが無い

## Alternatives Considered

- **既存の原画のコマを組み合わせて組む**(0010 の Consequences にある、傘の途中のコマを原画の立ち姿へ載せて組んだやり方) — 比べた記録は無い
- ほかに比べた案の記録は無い
